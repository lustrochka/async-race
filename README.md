## 🚗 Async-race

An interactive racing game where players can race cars, each with a different speed determined by an API. The game allows players to start races with multiple cars or run them individually

## 🚀 Deployment

A [server-side](https://github.com/mikhama/async-race-api) application must be installed for deployment to work

[Deploy](https://rolling-scopes-school.github.io/lustrochka-JSFE2023Q4/async-race/)

## 🛠️ **Key Features**

- **Garage View**:  
  - CRUD operations for managing cars (name & color).  
  - Color picker with live preview.  
  - Pagination (7 cars per page) and random car generation (100 at a time).  

- **Car Animations**:  
  - Start/stop engine buttons with smooth animations.  
  - Responsive design, adaptable to screens as small as 500px.  

- **Race Animation**:  
  - Start race with all cars on the page, with a reset button.  
  - Displays the winner's name after each race.  

- **Winners View**:  
  - Displays cars with the most wins, best times, and stats.  
  - Sort and paginate by wins and best times.

## 📜 **Technical Details**

- **SPA Architecture** with asynchronous operations.  
- **Animations**: JavaScript + CSS for engine and race animations.  
- **Responsive**: Ensures compatibility across devices (500px+).  

## 🔧 Installation and Setup

1. Clone server application

```sh
  git clone https://github.com/mikhama/async-race-api.git
```

2. Install NPM packages

```sh
  npm install
```

3. Start local server

```sh
  npm run start
```

4. Clone the repository

```sh
  git clone https://github.com/lustrochka/async-race.git
```

5. Go to folder async-race

```sh
  cd async-race
```

6. Install NPM packages

```sh
  npm install
```

8. Start project

```sh
  npm run start
```
